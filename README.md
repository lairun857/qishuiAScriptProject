# 汽水音乐自动听歌脚本（安卓 · 小米 14）

作者：[lairun857](https://github.com/lairun857) ｜ 仓库：<https://github.com/lairun857/qishuiAScriptProject>

一个基于 **AScript** 安卓引擎的自动化脚本：自动打开汽水音乐、看广告、领取「免费听」时长，领满当天额度后自动停止。

> ## 📱 不想用电脑？直接手机装（推荐新手）
> 进 [`手机直装版/`](手机直装版/) 目录，下载那**一个** `__init__.py` 文件，按里面的
> [手机端安装说明](手机直装版/手机端安装说明.md) 操作：**不用电脑、不用数据线、连 IP 都不用填**，
> 手机上自己建工程就能跑。小米 14 连屏幕参数都不用改。

> ## ✅ 用电脑的话，一句话上手
> 把项目下载到电脑 → **只改 `__init__.py` 顶部的两行屏幕参数**（小米 14 已经是默认值，不用改）→ 用 AScript 连上手机 → 点运行。其余代码一个字都不用动。

> ## ⚠️ 使用前必读
> 本脚本只是代替你点击官方广告、领取官方免费权益。请自行评估平台用户协议与账号风险；每日有领取上限，脚本领满会自己退出，不建议长时间无人值守挂机。

## 📱 手机直装版（不用电脑）

**适合：只有一台手机、不想折腾电脑环境和数据线的人。**

`手机直装版/__init__.py` 是一个**自包含的单文件脚本**，不依赖任何图片或其他代码。下载这一个文件就能在手机上独立运行：

1. 手机浏览器打开仓库 → 进 `手机直装版` 文件夹 → 点 `__init__.py` → 点 **Raw** → 下载保存。
2. 用文件管理 App 新建文件夹 `AScript/qishui`，把文件放进去，**确保文件名正好是** `__init__.py`。
3. 小米 14 不用改任何东西；其他手机打开文件把顶部 `SCREEN_W` / `SCREEN_H` 改成你的分辨率。
4. 打开 AScript App → 工程管理 → 导入这个工程 → 点「运行」，授权弹窗全部允许。

> 全程不需要电脑、数据线、WiFi 设备服务，也不用填手机 IP。
> 完整图文步骤见 [手机端安装说明](手机直装版/手机端安装说明.md)。

**两种方式功能完全一样**，区别只是安装途径：想省事就用手机直装版，想用电脑同步/跑测试就用下面的完整版流程。

## 一、它能做什么

脚本启动后会自己完成下面这一整套流程，不需要你守着：

```text
打开汽水音乐 → 跳过开屏广告 → 清理弹窗 → 确认停在首页
   → 点右下角「免费听N天」胶囊进广告
   → 等倒计时结束（自动处理直播诱导、短剧挽留、跳转劫持）
   → 点「领取成功」→ 点「领取奖励」→ 自动进入下一轮
   → 领满当天额度 / 连续 10 轮没领到 → 自动退出并打印统计
```

针对小米 14 做了专门适配：

| 遇到的坑 | 脚本怎么处理 |
| :--- | :--- |
| 被系统拉到「应用使用情况数据」页 | 自动按返回键离开并拉回汽水音乐，日志提示开启权限 |
| 新版入口从右上角「免」字移到右下角胶囊 | 优先用 OCR 按「免费听」文字定位，与分辨率无关；找不到才用比例坐标兜底 |
| 广告里「完成互动，领取奖励福利」挽留层 | 点「继续互动」恢复计时，绝不按返回键白丢一轮 |
| 误进直播间、右上角 × 关不掉 | 先点「继续观看」，不行再返回键，仍卡死才强制拉回 App |
| 「领取成功」识别不稳 | OCR 没命中就查无障碍控件树兜底 |

## 三、手把手安装（傻瓜式 6 步）

### 第 1 步：把项目下载到电脑

打开电脑终端（Windows 按 `Win + R`，输入 `cmd` 回车），选一个你喜欢的文件夹，执行：

```bash
git clone https://github.com/lairun857/qishuiAScriptProject.git
cd qishuiAScriptProject
```

> 不会用 Git？也可以直接在网页点绿色 **Code** 按钮 → **Download ZIP** → 下载后解压，效果一样。

### 第 2 步：手机装好 AScript 并开权限

1. 打开手机上的 **AScript App**。
2. 按提示开启这三项权限，**全部点允许**：
   - **无障碍服务**（脚本靠它点击屏幕）
   - **屏幕录制**（脚本靠它读屏幕文字）
   - **悬浮窗**
3. 进 AScript 的「**开发者**」页面，打开「**设备服务**」，记下端口号，默认是 `9096`。

### 第 3 步：查出手机的 IP 地址

在手机上：**设置 → WLAN（无线局域网）→ 点一下你正在连的 WiFi → 查看 IP 地址**。

会看到类似 `192.168.1.23` 这样的一串数字，记下来。

### 第 4 步：把 IP 填进配置（唯一需要填的手机信息）

用 VS Code 打开刚才下载的 `qishuiAScriptProject` 文件夹，找到并打开 `.vscode/settings.json`，把里面的示例 IP 换成你自己的：

```json
{
  "ascript.platform": "Android",
  "ascript.deviceId": "192.168.1.100:9096"
}
```

把 `192.168.1.100` 改成你第 3 步查到的 IP，例如你手机是 `192.168.1.23`，就写成：

```json
"ascript.deviceId": "192.168.1.23:9096"
```

> 端口 `9096` 一般不用改，除非你在 AScript 里改过设备服务端口。

### 第 5 步：修改屏幕参数（唯一需要改的代码）

打开根目录下的 `__init__.py`，**只看文件最开头的这一小块**：

```python
# ================================================================
#  ★★★ 使用前唯一需要改的地方：手机屏幕参数 ★★★
# ================================================================
SCREEN_W = 1200     # 屏幕宽度像素；小米 14 = 1200；其他机型按实际填写
SCREEN_H = 2670     # 屏幕高度像素；小米 14 = 2670；其他机型按实际填写
```

- **小米 14 用户**：这里已经是 `1200` / `2670`，**直接跳过这一步**。
- **其他机型**：把这两个数字改成你手机的分辨率宽和高即可，**其他任何代码都不要动**。

不知道自己手机分辨率？看这里 → [四、唯一要改的代码：屏幕参数](#四唯一要改的代码屏幕参数)。

### 第 6 步：确认电脑和手机连上了

1. 确保电脑和手机连的是**同一个 WiFi**。
2. VS Code 左侧打开 **AScript 面板**，能看到你的手机 IP 显示为「在线」就成功了。
3. 如果显示离线，回去检查第 2、3、4 步。

## 四、唯一要改的代码：屏幕参数

整个项目**只有 `__init__.py` 顶部这两行是需要你按手机修改的**：

```python
SCREEN_W = 1200     # 屏幕宽度（像素）
SCREEN_H = 2670     # 屏幕高度（像素）
```

### 怎么查自己手机的分辨率？

- **方法一**：手机「设置 → 我的设备 → 屏幕」，找「分辨率」。
- **方法二**：AScript 面板连上手机后，运行一次工程，日志第一行会打印 `屏幕尺寸: 1200 x 2670`，照着填就行。
- **方法三**：把 `SCREEN_W` 和 `SCREEN_H` 都填 `0`，脚本会自动读取手机屏幕尺寸。但个别机型读出来的值不准，点击会偏移，**建议还是手填**。

### 常见机型参考

| 机型 | SCREEN_W | SCREEN_H |
| :--- | :--- | :--- |
| 小米 14（本项目默认） | 1200 | 2670 |
| 常见 1080P 安卓机 | 1080 | 2400 |
| 部分 1.5K 屏机型 | 1260 | 2800 |

> 分辨率只影响兜底坐标和点击边界校验；免费听入口优先靠文字识别定位，所以大多数机型即使宽高略有出入也能正常跑。

## 五、运行起来

1. 手机打开**汽水音乐**，确认已登录、停在首页。
2. VS Code 打开本项目，左侧点 **AScript 面板**，确认设备在线。
3. 点「**运行工程**」，脚本会自动同步到手机并开始执行。
4. 首次运行会再弹一次授权提示，**全部同意**即可。
5. 之后手机会自己点、自己看、自己领，你可以把手机放一边。想看进度就盯日志，会打印每一轮的动作和成功次数。

### 先自测一下（可选，不消耗手机）

在电脑终端、项目目录下执行，可以验证脚本语法和逻辑没坏：

```bash
python -m py_compile __init__.py tests/test_qishui_android.py
python -m unittest discover -s tests -v
```

看到 `OK` 和 `30 tests` 全绿就说明工程是好的，跟手机无关。

## 六、脱离电脑自己跑（可选）

脚本本身不需要电脑持续参与，同步到手机后就能独立运行：

### 方式一：手机端直接运行

1. 手机打开 **AScript App**。
2. 进「**工程管理**」→ 找到 `qishuiAScriptProject`。
3. 点「**运行**」。

### 方式二：防止被系统杀后台（重要）

不做这几项，跑几分钟就会被系统清理掉：

| 设置项 | 路径（小米为例） | 作用 |
| :--- | :--- | :--- |
| 后台运行 | 设置 → 应用设置 → 应用管理 → AScript → 省电策略 → 无限制 | 防止后台被杀 |
| 自启动 | 同上 → 自启动 → 允许 | 允许后台存活 |
| 不锁屏 | 开发者选项 → 屏幕常亮 / 充电时不锁定屏幕 | 双保险 |

脚本内部已调用 `Device.keep_screen_on()` 保持常亮，每轮还会唤醒屏幕，息屏也能恢复。

### 方式三：打包成独立 APK（更彻底）

AScript App → 首页「**打包独立程序**」→ 选 `qishuiAScriptProject` → 生成 APK 安装，之后桌面直接点图标就能跑，连 AScript App 都不用开。

### 定时每天跑

AScript 没有内置定时器，可以用手机系统自带能力：小米「设置 → 更多设置 → 定时任务 / 自动任务」新建定时启动 AScript；或装 Tasker / MacroDroid 定时启动。

## 七、常见问题排查

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| 插件显示设备离线 | 没开设备服务 / 不在同一 WiFi / IP 填错 | 重开 AScript 设备服务，核对 IP，确认同 WiFi |
| 老跳到「应用使用情况数据」页 | 没给 AScript 开「使用情况访问」权限 | 设置 → 应用管理 → AScript → 权限 → 开启「使用情况访问」 |
| 入口点了没进广告 | 汽水音乐没停在首页 / 入口文案变了 | 手动停回首页；用 AScript 的 OCR 工具看右下角胶囊文字，必要时把它加进 `FREE_LISTEN_KEYWORDS` |
| 一直领不到奖励 | 当天额度已领完 / 广告没看完 | 属正常，脚本识别到领满提示会自动退出 |
| 点击位置整体偏移 | 屏幕尺寸填错 | 回到 `__init__.py` 顶部把 `SCREEN_W` / `SCREEN_H` 改成实际分辨率 |
| 提示 `uvx` 或 Python 相关报错 | 电脑环境没装好 | 终端执行 `uvx --version`、`python --version` 确认，缺什么装什么 |
| 想知道脚本卡在哪个页面 | 需要看现场 | 手机 SD 卡根目录找 `dbg_*.png`，是脚本异常时自动截的图 |

## 八、项目结构

```text
qishuiAScriptProject/
├── 手机直装版/
│   ├── __init__.py                 # 单文件完整脚本（下载这一个即可手机独立运行）
│   └── 手机端安装说明.md            # 不用电脑的安装图文教程
├── __init__.py                     # 安卓版主入口（AScript 工程约定，必须叫这个名字）
├── tests/
│   └── test_qishui_android.py      # 30 组零真机依赖单元测试（纯标准库）
├── .github/workflows/test.yml      # GitHub Actions 自动跑测试
├── res/img/                        # 图标资源
├── .vscode/
│   ├── settings.json               # 平台 / 设备地址（在这里填手机 IP）
│   └── .syncignore                 # 手机端同步排除规则
├── .trae/rules/ascript.md          # AScript 编码规则
└── README.md                       # 本说明文档
```

> `.syncignore` 已配置好，同步到手机时会自动排除 `tests/`、`.github/`、文档等无关文件，只有脚本本身和必要资源会上传。

## 九、其他可调参数（一般不用动）

都在 `__init__.py` 里，想微调再改：

| 常量 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `AUTO_CLICK_MIAN` | `True` | `True` 全自动；`False` 半自动（你手动点第一次，之后脚本接管） |
| `FREE_LISTEN_KEYWORDS` | `("免费听", "看广告免费", "免费听歌")` | 入口文字识别关键词，入口改版时在这里补 |
| `MIAN_X_RATIO` / `MIAN_Y_RATIO` | `0.796` / `0.828` | 入口兜底比例坐标，点击偏移时才微调 |
| `SELECTOR_MODE` | `2` | 无障碍控件检索模式（root 设备改 `9`，HID 改 `6`） |
| `FIRST_ROUND_TIMEOUT` | `70` | 首轮等广告结束超时（秒） |
| `AD_COUNTDOWN_TIMEOUT` | `65` | 单轮广告等待超时（秒） |
| `MAX_AD_TIMEOUT` | `95` | 动态倒计时延长上限（秒） |
| `LOOP_INTERVAL` | `3` | 每轮间隔秒数 |
| `MAX_LOOP_COUNT` | `100` | 最大循环次数 |
| `MAX_IDLE_ROUNDS` | `10` | 连续空跑退出阈值 |
| `KEEP_SCREEN_ON` | `True` | 屏幕常亮 |
| `AUTO_RESTART_APP` | `True` | 连续失败时自动重启 App |
| `OCR_ENGINE` | `"paddle"` | OCR 引擎（`paddle` 准 / `mlkit` 快） |
| `DEBUG_SNAPSHOT` | `True` | 异常时自动截图到手机 SD 卡根目录，稳定后可改 `False` |
