# 手机直装版 · 不用电脑不用数据线的安装说明

> 作者：lairun857 ｜ 仓库：https://github.com/lairun857/qishuiAScriptProject

这个目录里只有一个关键文件 **`__init__.py`**，它本身就是完整脚本，**不依赖任何图片或其他文件**。
你不需要电脑、不需要数据线、不需要 VS Code，直接在手机上就能把它变成可运行的工程。

---

## 准备条件（手机端）

1. 手机已安装 **AScript App**（应用商店或 ascript.cn 下载）。
2. 手机已安装并登录 **汽水音乐**。
3. 已给 AScript 开启 **无障碍服务**、**屏幕录制**、**悬浮窗** 三项权限。
4. 知道你手机的屏幕分辨率（小米 14 = 1200×2670）。

---

## 方法一：用手机浏览器直接下载（最省事）

### 第 1 步：下载这个文件

手机浏览器打开仓库地址：

```
https://github.com/lairun857/qishuiAScriptProject
```

进入 `手机直装版` 文件夹 → 点 `__init__.py` → 点右上角「**Raw**」（原始内容）→
再点右上角三个点 →「**下载** / 保存到文件」。

> 下载下来的文件可能叫 `__init__.py` 或 `download`，都一样，下一步会重命名。

### 第 2 步：在手机里建一个工程文件夹

用手机「文件管理」App，在内部存储根目录新建一个文件夹，例如：

```
AScript/qishui
```

把刚下载的文件放进去，并**确保文件名正好是** `__init__.py`（注意是英文双下划线）。

> 文件名必须叫 `__init__.py`，这是 AScript 的工程入口约定，叫别的名字跑不起来。

```
AScript/
└── qishui/
    └── __init__.py      ← 就这一个文件，够了
```

### 第 3 步：改屏幕参数（只改两行，小米 14 可跳过）

用手机自带的文件编辑器打开 `__init__.py`，拉到开头，找到这两行：

```python
SCREEN_W = 1200
SCREEN_H = 2670
```

- **小米 14**：默认就是 `1200` / `2670`，**不用改，直接下一步**。
- **其他手机**：把这两个数字换成你手机的屏幕宽高，**其余任何地方都别动**。

> 不知道分辨率？手机「设置 → 我的设备 → 屏幕」查看。

### 第 4 步：在 AScript 里导入并运行

1. 打开 **AScript App** →「**工程管理**」。
2. 点「**导入工程** / 扫描本地工程」，选中刚才建的 `AScript/qishui` 文件夹。
3. 工程出现在列表里后，点它 → 点「**运行**」。
4. 首次运行弹出的授权提示，**全部点允许**。
5. 手机会自己打开汽水音乐、看广告、领奖励，日志里能看到每一轮的动作。

搞定。全程没有电脑、没有数据线、没有 WiFi 设备服务。

## 方法二：从网盘 / 微信把文件发到手机

如果手机上网 GitHub 不方便，可以让朋友把这个 `__init__.py` 文件通过微信、QQ、网盘发给你，
在手机上保存到 `AScript/qishui/__init__.py`，然后从**第 3 步**继续往下做，步骤完全一样。

## 常见问题

| 现象 | 处理 |
|---|---|
| AScript 里找不到工程 | 确认文件夹里文件名正好是 `__init__.py`；用「扫描本地工程」重新扫一次 |
| 运行报错说找不到模块 | 确认文件没被下载工具改名（如 `__init__.py.txt`、`download`），必须是纯 `__init__.py` |
| 点击位置整体偏移 | 屏幕参数填错了，回第 3 步把 `SCREEN_W` / `SCREEN_H` 改成实际分辨率 |
| 一运行就跳到系统设置页 | 给 AScript 开启「使用情况访问」权限 |
| 提示没有无障碍/录屏权限 | 回到手机设置，把三项权限都打开 |
| 想看脚本卡在哪 | 手机内部存储根目录找 `dbg_*.png`，是异常时自动截的图 |

## 和完整版有什么区别？

**没有区别**，脚本功能完全一样。区别只在安装方式：

| | 完整版（仓库根目录） | 手机直装版（本目录） |
|---|---|---|
| 脚本功能 | 完全相同 | 完全相同 |
| 怎么装 | 电脑 clone → VS Code 同步到手机 | 手机下载单个文件 → 自己建工程 |
| 需要电脑/数据线 | 需要 | **不需要** |
| 需要改什么 | 手机 IP + 屏幕参数 | **只改屏幕参数**（连 IP 都不用填） |

> 想用电脑方式安装、或想跑自动化测试，去看仓库根目录的 [README.md](../README.md)。
